# Task 3: Temperature Calculator Web App

A lightweight utility web application that processes real-time numeric calculations across global temperature metrics.

##  Core Features
* Real-time calculation outputs without page refreshes.
* Supports accurate conversion across Celsius, Fahrenheit, and Kelvin scales.
* Input validation mechanisms protecting against empty inputs or script injection.

## Tech Stack
* HTML5
* CSS3 
* JavaScript (ES6 DOM Event Listeners & Logic Engines)
